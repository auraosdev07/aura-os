# Project

Name: Aura OS

Purpose:
Aura OS is an AI Workforce Operating System where AI employees work together inside a virtual company.

The product is NOT a chatbot.
The product is NOT a normal AI assistant.

It is an operating system for managing AI employees, missions, knowledge and company workflows.

---

# Core Principles

- AI behaves like employees.
- Everything is mission driven.
- Modular architecture.
- Production-ready code only.
- No fake/demo implementations.
- Scalability first.
- Clean UI.
- Documentation before major systems.

# Managers

Managers coordinate work.

Managers do not perform implementation.

Managers:

- assign work
- review work
- approve work
- coordinate employees

---

# AI Employees

Every employee has:

- Profile
- Department
- Manager
- Status
- Mission
- Memory
- Artifacts
- Performance

Employees are persistent.

They are not temporary chat sessions.
